# prompt-refiner

**簡報提示詞優化器** — Claude Skill

---

## 功能

貼入一段簡報需求草稿，自動輸出：

1. **精準化提示詞**：補齊角色、範圍、產出、標記定義、風格與色碼五要素
2. **配色推薦**：2–3 組方案，附十六進位色碼與適用場合說明

---

## 觸發方式

以下任何說法都會啟動：

- 「幫我修這段提示詞」
- 「這樣寫夠精準嗎？」
- 「配色建議」
- 「幫我選顏色」
- 貼上簡報草稿 + 「這樣可以嗎？」

---

## 輸出範例

```
你是一位資深 CFO 財務顧問。

針對董事會年度策略報告，製作一份邏輯嚴謹、數據導向的簡報...

視覺規格：
版面 16:9，標題 36pt、內文 18pt、最小 12pt
主色 #1E2761、輔色 #CADCFC、背景白 #FFFFFF、內文深灰 #2A2A2A
頁尾名牌：Ann Cheng

輸出：PPTX，共 10 頁。
```

配色推薦：
- 🔵 深夜行政藍 `#1E2761` · `#CADCFC` — 適合董事會、嚴謹權威場合
- 🟢 青藍信任 `#028090` · `#00A896` — 適合 ESG、金融科技報告

---

## 安裝

下載 `prompt-refiner.skill` 並上傳至 Claude.ai → Settings → Skills。
